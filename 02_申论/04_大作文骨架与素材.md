# 大作文骨架与素材

> 执法卷第 5 题，40 分，1000–1200 字，55 分钟。
> **按档给分**：决定档次的是"论点清不清楚、结构完不完整、有没有跑题"，不是文采。
> 不会写，通常是因为没有骨架，不是词汇量不够。

---

## 一、阅卷老师实际在看什么

一篇 1000 字的文章，阅卷大约 60 秒。他会看五个地方：

| 看哪儿 | 找什么 | 你该做什么 |
| --- | --- | --- |
| 标题 | 有没有观点 | 标题里要有动词、有态度 |
| 开头结尾 | 总论点在哪 | 开头最后一句必须是总论点 |
| 三个分论点句 | 是不是并列、是不是扣题 | 每段第一句就是论点，句式统一 |
| 段落中间 | 有没有例子、有没有分析 | 论点 + 阐释 + 例证 + 回扣 |
| 字数、卷面 | 够不够、清不清楚 | 1000 字以上，少涂改 |

**没有"分论点句"的文章，直接掉一档。** 这是最容易补的一项。

---

## 二、骨架（背下来，五段）

```
标题（12 字以内，有动词）

【开头】150 字
  第一句：背景/政策
  第二句：问题/现象
  第三句：总论点（"因此，……"）

【分论点一】250 字
  首句：论点
  阐释：为什么
  例证：材料里的做法 / 常见做法
  回扣：所以……

【分论点二】250 字
【分论点三】250 字

【结尾】150 字
  重申总论点 + 升华（法治政府 / 为民服务 / 基层治理）
```

字数分配：150 + 750 + 150 ≈ 1050，达标。

---

## 三、标题三式（选一个，30 秒）

| 式 | 例子 | 适合 |
| --- | --- | --- |
| 动宾式 | 《以柔性执法护航营商环境》 | 最稳，不会错 |
| 对仗式 | 《执法有力度 服务有温度》 | 有文采，但要对得上 |
| 判断式 | 《"首违不罚"不是"一罚了之"》 | 有观点，适合短评式命题 |

**别写**：《论行政执法》《谈法治》——没有观点，阅卷第一眼就低一档。

## 四、开头三句（150 字，8 分钟）

```
近年来，××（政策/背景）持续推进，××（领域）取得明显成效。
但与此同时，××（问题）仍然存在，××（危害）。
因此，必须××（总论点），才能××（目的）。
```

**总论点必须是"做法 + 目的"**，不能只是"很重要"。
- 差："行政执法很重要。"
- 好："必须把柔性执法落到每一个执法环节，才能让法治真正成为最好的营商环境。"

---

## 五、分论点三种句式（三个必须并列、必须扣题）

**句式 A（推荐，最好写）**：`以××促××`
- 以规范执法促公平正义
- 以柔性执法促营商环境
- 以数字执法促效能提升

**句式 B**：`××是××的基石/关键/保障`
- 规范执法是法治政府的基石
- 队伍建设是执法效能的保障

**句式 C**：`坚持××，让××`
- 坚持过罚相当，让执法更有尺度
- 坚持执法为民，让服务更有温度

**三个分论点要"同一层级"**：不能一个讲制度、一个讲技术、一个讲"要加强领导"（后者是空话，且层级不同）。

## 六、每一段怎么写（250 字，4 步）

```
① 论点句（30 字）：以柔性执法促营商环境。
② 阐释（60 字）：为什么这条重要——过罚相当、处罚与教育相结合。
③ 例证（100 字）：材料里的做法，或"某地推行首违不罚清单，一年减免罚款××万元"。
④ 回扣（60 字）：因此，……（回到总论点）。
```

**例证从材料里拿最稳**：材料给了"综合查一次""执法码""首违不罚 320 件"，直接改造使用，既扣题又不会被判"脱离材料"。

---

## 七、结尾两式（150 字）

**式一（推荐）**：重申 + 升华
```
执法一头连着政府，一头连着群众。只有把××落实到每一个环节，
才能让人民群众在每一项执法决定中感受到公平正义。
```

**式二**：展望
```
面向未来，随着××的深入推进，××必将……
```

**别写**："综上所述，我认为……"（口语）；也别喊口号（"让我们携手共进！"）。

## 八、素材三类（够用就行，不要贪多）

### 制度（写"有依据"）

- **行政执法"三项制度"**：行政执法公示、执法全过程记录、重大执法决定法制审核
- **行政处罚法（2021 修订）**：首违不罚、过罚相当、处罚与教育相结合
- **行政复议法（2023 修订，2024 年起施行）**：化解行政争议的主渠道
- **"放管服"改革 / "双随机、一公开" / 信用监管 / 综合行政执法改革**

### 方法（写"怎么做"）

- 说理式执法、柔性执法、包容审慎监管
- 首违不罚 + 告知承诺 + 限期整改（闭环，不是"不罚了之"）
- "综合查一次"、跨部门联合检查、执法码 / 数字留痕
- 执法 + 服务（送法上门、合规指导）

### 表述（写"像申论"）

- 法者，治之端也。（《荀子》）
- 天下之事，不难于立法，而难于法之必行。（张居正）
- 法治是最好的营商环境。
- 让人民群众在每一项法律制度、每一个执法决定、每一宗司法案件中都感受到公平正义。

**每条素材只记一句话 + 一个用法**。背十句不会用，不如记三句会用。

## 九、四个常见跑题

| 跑题 | 表现 | 怎么防 |
| --- | --- | --- |
| 脱"执法" | 写成"诚信建设""公民道德" | 标题、分论点、结尾各出现一次"执法/法治" |
| 只谈意义 | 三个分论点都是"很重要" | 每条必须落到"怎么做" |
| 分论点不并列 | 一个是制度、一个是"加强领导" | 三条同一层级，句式统一 |
| 脱离材料 | 全篇用自己背的例子 | 每段至少一个材料里的做法 |

## 十、练习法（不要一上来就写 1000 字）

**第 1 步（25 分钟，先做 3 次）**：只写骨架——
标题 + 开头最后一句（总论点）+ 三个分论点句 + 结尾第一句。
**五个句子，能立住，文章就立住了。**

**第 2 步（55 分钟）**：按骨架成文，卡时间。

**第 3 步（10 分钟）**：只看三件事——三个分论点是否并列、是否扣题、有没有一段没有例子。

3 篇之后，你会发现大作文是这套卷子里**最可控**的一道题：它不考你知不知道，只考你有没有结构。
