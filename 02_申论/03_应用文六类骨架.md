# 应用文六类骨架

> 执法卷第 4 题基本固定是应用文（400–500 字）。
> 格式占约 20%，**缺标题、缺称谓、缺落款是白扣的分**；剩下 80% 还是"要点全不全"。
> 一天背一类，六天一轮。

---

## 通用格式清单（写之前先默一遍）

```
        标题（居中，一行）
称谓：（顶格，冒号）

正文（分段，分条）

                    落款单位（右）
                    日期（右）
```

| 项 | 规则 | 什么时候可以省 |
| --- | --- | --- |
| 标题 | 发文机关 + 关于 + 事由 + 的 + 文种 | 题干说"拟写"可省机关名，但标题必须有 |
| 称谓 | 顶格 + 冒号 | 简报、短评可省 |
| 落款 | 单位名 + 日期 | 讲话稿、短评可省 |
| 日期 | 用题干给的时间，没给就写"××××年××月××日" | 同上 |

---

## 一、通知（下行文，最常考）

**一句话**：告诉下级"要做什么、怎么做、什么时候做完"。

```
关于开展××专项整治的通知

各××单位：

    为进一步××（目的），根据××（依据），决定开展××专项整治。现将有关事项通知如下：

    一、整治重点。……
    二、工作步骤。……（时间节点）
    三、工作要求。……（加强领导、压实责任、及时报送）

                                    ××局
                                ××××年××月××日
```

**句式**：`为进一步……，根据……，现将有关事项通知如下：`
**坑**：忘主送机关；把"事项"写成了议论；结尾不写"请遵照执行/请及时报送"。

---

## 二、倡议书（面向群众/企业，柔性）

**一句话**：**请**大家一起来做，不是**要求**大家做。

```
关于××的倡议书

广大市民朋友们：

    ××（背景/问题）。为此，我们向全体市民发出如下倡议：

    一、做××的践行者。……
    二、做××的监督者。……
    三、做××的宣传者。……

    让我们携起手来，共同……

                                    ××单位
                                ××××年××月××日
```

**句式**：`为此，我们向全体发出如下倡议：` / `让我们……`
**坑**：语气写成命令（"必须""严禁"）；忘落款；倡议内容和对策题混同。

---

## 三、讲话稿（领导口吻，有对象感）

**一句话**：开头有称呼，中间讲三点，结尾有号召。

```
在××工作会议上的讲话

同志们：

    今天召开这次会议，主要任务是××。下面，我讲三点意见。

    一、充分肯定成绩，正视存在问题。……
    二、聚焦重点任务，狠抓工作落实。……
    三、强化责任担当，确保取得实效。……

    同志们，……（号召）
```

**句式**：`下面，我讲三点意见：` / `同志们，……`
**坑**：忘称谓；结尾写成"特此通知"；用第三人称说"该局"。

---

## 四、简报（给上级看的情况反映）

**一句话**：什么时间、谁、做了什么、效果如何。

```
××工作简报
第 × 期

    ××年××月××日，××（单位）……（做了什么），取得明显成效。

    一、主要做法。……（2–3 条）
    二、取得成效。……（数据）
    三、下一步打算。……

                        报送：××   编发：××
```

**句式**：`近日，……，取得明显成效。`
**坑**：写成工作总结（大段议论）；忘期号；做法不分条。

---

## 五、短评（评论员文章，要有观点）

**一句话**：先讲一件事，再评这件事，最后给个态度。

```
"首违不罚"不是"一罚了之"

    近日，××（新闻由头）。这一做法引发关注。

    （分析）……表面看是……，实质是……。一方面……，另一方面……。

    （结论）执法既要有力度，也要有温度。……
```

**句式**：`近日，……引发关注。` / `表面看是……，实质是……`
**坑**：写成消息（只叙述不评论）；没有明确观点；结尾没有态度。

---

## 六、建议（给领导/上级，务实）

**一句话**：问题一句带过，建议分条写实。

```
关于进一步推进××工作的建议

××领导：

    目前，××工作仍存在××、××等问题。为此，提出以下建议：

    一、健全××机制。……
    二、加强××保障。……
    三、强化××考核。……

    以上建议，供参考。

                                    ××
                                ××××年××月××日
```

**句式**：`针对……问题，提出以下建议：` / `以上建议，供参考。`
**坑**：只提问题不给措施；措施空泛（"加强领导""提高认识"）；忘主送。

---

## 六个文种的一句话区分

| 文种 | 谁对谁说 | 核心动词 | 有没有落款 |
| --- | --- | --- | --- |
| 通知 | 上对下 | 要求、部署 | 有 |
| 倡议书 | 对群众/企业 | 号召 | 有 |
| 讲话稿 | 领导对参会者 | 强调、部署 | 通常无 |
| 简报 | 下对上 | 反映、汇报 | 有报送栏 |
| 短评 | 媒体对读者 | 评论 | 无 |
| 建议 | 下对上 | 建议 | 有 |

**背这六行就够判断文种**：先问"谁对谁说"，再问"要对方干什么"。

---

## 练习方法（第 3 周，一天一类）

1. 只看骨架，默写格式（标题/称谓/正文/落款位置），30 秒。
2. 拿一份材料，按骨架写一篇（400 字，25 分钟）。
3. 对照：格式缺项？要点几条？有没有一条是"加强领导"这类空话？

六天之后，看到"写一份"三个字，先动笔写格式框，再填内容——**格式分是白送的，别丢。**
