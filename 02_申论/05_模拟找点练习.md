# 模拟找点练习（3 题）

> **这是模拟材料，不是真题。** 用它练方法（审题、找点、自评），不要背它的答案。
> 真题到了之后，把同样的流程套到真题上，这套材料就可以扔掉。
> 建议：分三天做，一天一题；每题先只列点，再对答案。

---

## 材料

为进一步优化营商环境、减轻企业负担，A 市 B 区自 2024 年起推行"综合查一次"改革。

过去，一家餐饮店一年要接受市场监管、消防、城管、卫健等多个部门检查十几次，每次都要准备一批材料、停业半天配合。不少商户反映：检查多、标准不一、反复整改，"同一个问题，三个部门三种说法"。

B 区把 12 个部门的 86 项检查事项合并成"一张清单"，对同一家企业同一时间只查一次、一次查完所有事项。进店前 3 天告知检查内容和所需材料，进店时一次性出示执法证件和检查清单。

对首次违法、危害后果轻微并及时改正的，依法不予行政处罚，改为"告知 + 承诺 + 整改"：执法人员当场说明违法事实和法律依据，经营者签署承诺书并限期整改，整改到位的复核后不予处罚。2024 年共办理"首违不罚"案件 320 件，为企业减免罚款 460 万元。

B 区还开发了"执法码"，商户扫码即可查看本次检查的依据、事项、结果和投诉渠道；执法人员的检查记录同步上传系统，超时未录入自动提醒。

改革后，涉企检查频次下降 62%，商户满意度从 78% 提升到 94%。但也有干部反映：合并检查后一次进店要查十几项，专业跨度大，"查不深、看不准"；个别部门担心"少查了出事担责"，仍然私下单独上门检查。

### 参考要点

**参考答案（约 195 字）：**

> 1. 整合检查事项。将 12 个部门 86 项检查事项合并为"一张清单"，同一企业同一时间只查一次、一次查完。
> 2. 规范检查程序。进店前 3 天告知检查内容和所需材料，进店时一次性出示执法证件和检查清单。

## 第 2 题（15 分，250 字）明天做

**请谈谈你对"首违不罚"的理解。**

> 练的是：**综合分析题的"三层结构"**——是什么 → 为什么 → 怎么办。
> 这题最容易写成"意义很重要"，然后 250 字全是好处。

### 参考要点

| 层 | 写什么 |
| --- | --- |
| 是什么 | 对首次违法、危害后果轻微并及时改正的，依法不予行政处罚（《行政处罚法》第 33 条），改为"告知 + 承诺 + 整改" |
| 为什么 | 过罚相当、处罚与教育相结合；减轻企业负担（320 件、460 万元）；优化营商环境；体现执法温度 |
| 边界 | 仅限"首次 + 轻微 + 及时改正"，不是"不罚了之"；整改不到位仍要依法处理；严重违法照旧严处 |
| 怎么做 | 制定"首违不罚"清单、统一裁量基准、规范程序、全程留痕 |

**参考答案（约 250 字）：**

> "首违不罚"是指对首次违法、危害后果轻微并及时改正的行为，依法不予行政处罚。它不是简单的"不罚了"，而是把处罚换成"告知、承诺、整改"的闭环。
>
> 这一做法有三重意义：一是体现过罚相当、处罚与教育相结合的原则，避免小错重罚；二是实实在在减轻企业负担，B 区一年减免罚款 460 万元；三是释放执法温度，改善营商环境。
>
> 但"不罚"有严格边界：必须同时满足首次、轻微、及时改正三个条件；整改不到位的，仍要依法处理；对危害安全、屡教不改的违法行为，必须严格执法。
>
> 因此，落实"首违不罚"，关键在清单明确、程序规范、全程留痕，既不能一罚了之，也不能一放了之。

### 自评

- 我写了几层？（1 层 = 只写了意义，需要重写）
- 有没有写边界？（不写边界，这题的档次上不去）
- 有没有用材料里的数字？（320 件、460 万元）

## 第 3 题（20 分，400 字）后天做

**假如你是 B 区市场监管局工作人员，请就进一步推进"综合查一次"改革，向局领导提出建议。**

> 练的是：**应用文格式 + 建议要落地**。
> 这题材料里已经给了两个问题（专业跨度大、部门怕担责），你的建议必须一条对一个问题。

### 参考骨架

```
关于进一步推进"综合查一次"改革的建议

局领导：

    （一句话说问题）目前改革已取得成效，但仍存在检查专业性不足、部门协同不畅等问题。
    为此，提出以下建议：

    一、组建联合检查队伍，提升专业能力。……
    二、建立结果互认和责任清单，消除部门顾虑。……
    三、强化数字监管，杜绝私下检查。……
    四、统一裁量标准，规范"首违不罚"。……

    以上建议，供参考。

                                    ××科  ××
                                ××××年××月××日
```

### 参考要点

| 问题 | 建议 |
| --- | --- |
| 一次查十几项，专业跨度大，"查不深、看不准" | 按行业组建联合检查组，配备专业骨干、建立专家库，开展跨领域培训 |
| 部门担心"少查了出事担责"，私下单独上门 | 制定检查责任清单，明确"查过即尽责"；实行检查结果互认，已查事项不重复检查 |
| （材料外的合理延伸） | 检查记录全量上传、异常预警，纳入考核监督；统一"首违不罚"清单和裁量基准；建立企业回访评价机制 |

**评分要点**：格式（标题、主送、落款、日期）20%；建议 4–5 条、每条"措施 + 目的"80%。
**扣分点**：只写问题不给措施；措施空泛（"加强领导""提高认识"）；忘主送或落款。

### 自评

- 建议几条？每条有没有落到"谁做什么"？
- 有没有一条是"加强领导"这类空话？删掉。
