# 申论审题四步

> 每题 60 秒，不动笔。做够 10 题之后，这四步会变成条件反射（大约 15 秒）。
> **审题错的题，写得再好也是从 0 分起步。**

---

## 第一步：判题型（15 秒）

| 题干里的标志词 | 题型 | 作答骨架 |
| --- | --- | --- |
| 概括、归纳、梳理、指出、列出……问题/做法/成效/原因 | **归纳概括** | 分条列点，只写材料里有的 |
| 谈谈对"……"的理解、分析……的原因/影响、对……进行评析 | **综合分析** | 是什么 → 为什么 → 怎么办 |
| 提出对策、建议、如何解决、怎么改进 | **提出对策** | 主体 + 做法 + 目的 |
| 假如你是……、拟写、起草、写一份…… | **贯彻执行（应用文）** | 格式 + 内容要点 |
| 结合材料、自拟标题、写一篇文章 | **文章写作** | 论点 + 结构 |

**判断题型的意义**：题型决定骨架。把概括题写成分析题（开始讲原因），把对策题写成概括题（只写问题不写做法），都会直接掉档。

---

## 第二步：定对象（20 秒，最容易错）

问什么答什么，多写一个字都是浪费格子。四个高频坑：

| 题干问 | 只能写 | 不要写 |
| --- | --- | --- |
| 问题 | 问题本身（"监管缺位""标准不一"） | 原因、对策 |
| 做法 | 动宾短语（"建立联合检查机制""开发执法码"） | "要重视""应加强" |
| 成效 | 变化（"频次下降 62%""满意度从 78% 升到 94%"） | 做法 |
| 原因 | 为什么（制度、人员、技术、利益） | 表现 |

**一个自检**：写完扫一眼，每个要点是不是都能回答题干那个问句。答不上的，删掉。

---

## 第三步：看限制（15 秒）

| 限制 | 怎么处理 |
| --- | --- |
| **字数**（如"不超过 300 字"） | 写到 90% 左右最稳；超字数阅卷不看，少太多显得点不全 |
| **条数**（如"分条作答""不少于 3 条"） | 宁多勿少，一条一个要点，序号用 1. 2. 3. |
| **身份**（如"假如你是执法人员"） | 决定权限和口吻：执法人员不能写"建议立法"，只能写"建议向上级反映" |
| **对象**（写给领导 / 群众 / 企业） | 决定称谓、语气、要不要落款 |
| **"有条理""层次清楚"** | 不是修辞要求，是**分条 + 同类合并**的要求 |

---

## 第四步：定格式（只对应用文，10 秒）

看到"写一份/拟写/起草"，先问：**这是什么文种？**

- 通知、倡议书、讲话稿、简报、短评、建议 → 各自的骨架见 [03_应用文六类骨架.md](03_应用文六类骨架.md)
- 格式占分不高，但**缺标题、缺称谓、缺落款会直接扣分**，而且是白扣的分

一句话：**内容要点决定 80%，格式决定 20%，但那 20% 是白送的。**

---

## 一个 60 秒的完整示例

题干：「根据给定资料 2，概括 B 区"综合查一次"改革的主要做法。（200 字，10 分）」

| 步骤 | 判断 | 结论 |
| --- | --- | --- |
| 判题型 | "概括……做法" | 归纳概括，分条列点 |
| 定对象 | 做法 | 全写动宾短语，不写成效、不写问题 |
| 看限制 | 200 字、10 分 | 大约 4–6 条，每条 30–40 字 |
| 定格式 | 无 | 不需要标题称谓 |

**如果这题问的是"改革取得了哪些成效"**，同样的材料，答案要换成"频次下降 62%、满意度 78%→94%"这类变化——**材料没变，答案完全不同**。这就是第二步的价值。

---

## 交卷前 30 秒检查（四问）

1. 每个要点，都在回答题干那个问句吗？
2. 分条了吗？序号清楚吗？
3. 字数在范围内吗？
4. 应用文：标题、称谓、落款、日期，缺哪个？

四问都过，这题的分基本就拿到了。
