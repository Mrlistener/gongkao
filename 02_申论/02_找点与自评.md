# 找点与自评

> 申论小题是**找点给分**：答案里有点就有分，没有就没有。
> 这一页只管一件事：**怎么把点找全，以及怎么知道自己漏在哪。**

---

## 一、找点的操作流程（12 分钟一题，8 分钟只列点）

**第 1 步：带着题读材料（2 分钟）**
先看题干问什么，再读材料。读的时候手里拿笔，只做标记，不写句子。

| 标记 | 对应 | 材料里的信号词 |
| --- | --- | --- |
| △ | 问题 | 缺乏、不足、滞后、难、投诉、反映、但是、然而 |
| √ | 做法 | 建立、实施、推行、整合、开发、通过、采取、开展 |
| ☆ | 成效 | 下降、提升、增长、满意度、从……到…… |
| ○ | 原因 | 由于、因为、根源在于、受……影响 |

**第 2 步：逐段过，一段一问（4 分钟）**
每段读完问自己：这段在说**问题、做法、成效还是原因**？只要说了，就至少出一个点。
**一段都没出点的段落，要回头再看一遍**——八成是漏了。

**第 3 步：合并同类（2 分钟）**
同类的合并成一条（"整合检查事项""减少检查频次"都是"优化检查方式"，可以并列也可以合并）。
**分条不是越多越好**：200 字大概 4–6 条，每条 30–40 字。

**第 4 步：写成动宾短语（1 分钟）**
- 好："整合 12 个部门 86 项检查事项，形成一张清单"
- 差："要重视检查事项的整合工作"（空话）、"检查事项很多"（这是问题，不是做法）

## 二、三类漏点（几乎所有失分都在这三类）

### 漏点一：漏段

**表现**：材料 5 段，你只用了 3 段。
**为什么**：某段看着"像背景介绍"，其实藏着要点。
**自检**：数材料段数，数自己用了几个来源段。对不上就回头补。

### 漏点二：漏主体

**表现**：全篇只写"政府应该……"，材料里明明有企业、群众、社会组织、媒体的做法。
**为什么**：习惯性把申论当成"政府工作报告"。
**自检**：写完列出你写到的主体，再回材料列出出现的主体，差集就是漏的。

### 漏点三：漏对策

**表现**：题目问"如何解决"，你写满了问题，对策只有一句"加强管理"。
**为什么**：问题好找（材料里都是抱怨），对策往往藏在后面的段落里。
**自检**：对策题里，对策条数应 ≥ 问题条数。

> 补充第四类（少见但要防）：**漏数据**。材料给了具体数字（"下降 62%""320 件"），概括成效时用上，比"显著下降"有力得多。

## 三、自评表（每做完一题，填一行）

复制这张表到你的笔记里，或者打印出来手填：

| 日期 | 题号 | 题型 | 作答对象 | 我的点数 | 参考点数 | 命中数 | 漏点类型（段/主体/对策） | 字数 | 用时 | 估分 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |  |  |  |

**估分口径**（粗估，够用）：
- 要点分 = 命中数 ÷ 参考点数 × 该题分值 × 0.8
- 结构分（分条、条理）满分 20%，基本都会给
- 字数超了或不足，扣 1–2 分

**每周做一次汇总**：把"漏点类型"那一列数一遍。
如果 10 题里有 6 题是"漏段"，那这周的任务就不是多做题，而是练"逐段过"。

## 四、材料里的点，长什么样（认得出才找得到）

| 信号 | 例子 | 提炼成 |
| --- | --- | --- |
| 顿号 / 分号列举 | "检查多、标准不一、重复整改" | 三个问题点，或合并成"多头检查、标准不一" |
| 数字 | "12 个部门 86 项合并为一张清单" | 整合检查事项 |
| 转折 | "但个别部门担心担责，仍私下上门" | 部门协同不足、责任边界不清 |
| 对策词 | "通过……""建立……""推行……" | 直接就是做法要点 |
| 引号里的原话 | "查不深、看不准" | 专业性不足（用自己的话概括） |
| 评价 | "商户满意度从 78% 升到 94%" | 成效 |

**一条经验**：材料里凡是"有人说话"的地方，几乎都有点——群众说的话是问题，干部说的话是难点，专家说的话是原因。

## 五、写答案的三条格式规矩

1. **序号 + 短句开头**：`1. 整合检查事项。将 12 个部门 86 项……`
   先给结论词，再给细节。阅卷是扫着找点的，结论词放句首命中率最高。
2. **一条一个意思**：不要把两个不相干的点塞进一条，也不要把一个点拆成三条凑数。
3. **不写过渡句**：`综上所述`、`首先其次` 之外的连接词，能省就省——省下来的字都是要点。

## 六、今天就能做的自评

做完 [05_模拟找点练习.md](05_模拟找点练习.md) 的第 1 题，只回答三个问题：

1. 我的点数 ______，参考点数 ______
2. 漏的点属于哪一类？（段 / 主体 / 对策 / 数据）
3. 下一题我要改的一个动作是：____________

把这三个答案写下来，比再做十道题有用。
