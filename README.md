# 考公资料库

## 怎么开始

双击仓库根目录的 **`启动练习.bat`**，浏览器会自动打开 http://127.0.0.1:8765/ 。

- 首页是「考公 · 今日」，四个入口：概念小测、第 1 套、记忆卡、错题集
- 每次交卷，成绩和错题会自动追加到 **`04_错题与笔记/答题记录.jsonl`**
- 关掉那个黑色窗口就停止服务；下次用再双击一次

直接双击 html 也能做题，只是记录只存在浏览器里，不会写进仓库。

## 怎么用（三档制）

时间不确定时不要用日期表，用清单：

- **A 档 45 分钟**：资料分析 2 篇（12′）+ 申论 1 题只列要点（8′）+ 法律时政碎片（10′）
- **B 档 90 分钟**：资料 1 套（25′）+ 判断专项（20′）+ 申论 1 题成文（20′）+ 法律（10′）
- **C 档 3 小时+**：行测整卷（120′）+ 复盘（40′）+ 申论/大作文（55′）

**铁律**：整卷至少 5 次，放周末；其他都能省，这个不能。

**断档规则**：漏了不补；只记做没做，不记时长；可连续三天只做 A 档，但不要 0。

## 提交约定

每次做完一个专题就提交一次，message 写清做了什么：

    feat(资料分析): 完成必得分类第2套，错在第3题
    feat(申论): 完成 2023 执法卷五题
    docs(计划): 调整第三阶段任务量

这样两周后的提交记录，就是一份比计划表更真实的复盘。

## 本仓库是公开的 · 隐私约定

**不放进来**：真实姓名、手机号、身份证号、准考证号、报名序号、工作单位、学校、微信/QQ 等联系方式；具体岗位名称与岗位代码（写到「成都市 · 行政执法类」这一级即止）。

**可以放**：报考城市、个人模拟成绩、岗位类别、备考计划与错题——这些都不指向具体个人身份。

提交者身份统一为 `Mrlistener <Mrlistener@users.noreply.github.com>`，不写真实姓名与工作邮箱。

提交前自查：`git -c core.quotepath=false grep -n -E '姓名|手机号|身份证|准考证'`

**自动拦截**：仓库带一个提交前钩子（`.githooks/pre-commit`，已通过 `core.hooksPath` 启用），
提交内容里出现真实姓名、工作邮箱、手机号、身份证号、私人邮箱时会直接拒绝提交。

注意：钩子只扫文本。`xlsx` 这类二进制文件扫不到，所以打卡表的备注栏别写手机号、别写具体单位。
