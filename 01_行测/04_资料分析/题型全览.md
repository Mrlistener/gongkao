# 资料分析题型全览

> 2026-11-15 做的一次全库抽样：四川 17 套 + 重庆 29 套的「资料分析」部分，共提取 **757 道题**，
> 按题干关键词自动归类。**约 1/4 未能自动归类**（多为求值题和图表题），所以下面的频次是**下限**，不是精确值。

## 三、这个频次说明什么

1. **综合分析占近两成**——四个选项逐个判，是耗时大户。不会做 = 直接丢 1 题 1 分，还会拖垮整篇。
2. **比重 + 平均数 + 增长量 + 增长率 = 233 题（31%）**——这四类是基本盘，公式固定，必须零失误。
3. **基期只占 1.7%**——反直觉。基期是入门第一课，但考得不多，别在这上面花太多时间。
4. **加总/范围只占 1.8%**——但它是“送分题”，两分钟能做完，遇到别跳。

## 四、优先级（按「分值 × 可提升空间」）

| 优先级 | 题型 | 理由 |
| --- | --- | --- |
| P0 | 综合分析 | 占比最高，且你完全没练过 |
| P0 | 比较类 | 占比高、你最慢，且已有“用增量代替增速”的错 |
| P1 | 比重 / 比重变化 | 基本盘，公式简单，必须全对 |
| P1 | 平均数 / 平均数变化 | 同上 |
| P1 | 增长量 / 增长率 | 同上 |
| P2 | 求值 / 加总 | 送分题，练两轮就够 |
| P2 | 基期 / 倍数 | 占比低，会就行 |
| P3 | 混合增长率 | 出现频率中等，但会了很快（30 秒） |

## 五、抽样方法的局限

- 自动分类靠关键词，**“约为多少”这类会漏**，所以“求值”被低估
- 部分 PDF 是扫描版，`pdftotext` 取不到文字，这类卷没进统计
- 重庆卷里有不少“联考共用卷”（多省同一份题），**同一道题可能被重复计数**
- 结论看**量级**，不要看个位数差异
