# 练习计时规则

## 怎么记

每道题在对话里出现两次时间戳：

- **出题时间**：我发题时打，格式 `【出题 14:32】`
- **作答时间**：你回复后我打，格式 `【作答 14:35 · 用时 3 分 10 秒】`

时间取自对话系统时间，误差在几秒内。

## 落到哪

`04_错题与笔记/练习计时.jsonl`，一行一条：

```json
{"set":"2025国考执法卷","q":"67","mod":"数量","ask":"14:32","ans":"14:35","sec":190,"result":"错","note":"84算成82"}
```

## 用来分析什么

1. **单题用时**：超过 90 秒的题，标出来单独看
2. **模块平均**：言语/判断/数量/资料各花多久
3. **超时题分布**：超时的题是"不会"还是"会但慢"
4. **正确率-用时**：找出"又快又对"和"慢且错"两类

目标不是快，是**知道时间花在哪**。
