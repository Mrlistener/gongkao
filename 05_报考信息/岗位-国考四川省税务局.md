## 四、申论可能的题材（重要判断）

2024 国考行政执法卷的**材料 5 全文是税务执法**（统一执法证件、罚款畸轻畸重、税务稽查、提高法律遵从度）。

**税务岗位的申论，出税务题材的概率不低。**

已练过的对应题：2025 国考执法卷“办好事 / 好办事 / 事办好”、2024 国考执法卷“力 / 理 / 利”。

## 五、税务主题词（申论、面试通用）

| 词 | 怎么用 |
| --- | --- |
| 减税降费 | 政策落地类题目的抓手 |
| 便民办税春风行动 | 税务系统每年的固定动作，举例好用 |
| 税收营商环境 | 评价地方发展环境 |
| **税法遵从度** | 执法目的——"不是处罚，而是提高遵从度" |
| 精确执法 | "认定讲证据、裁量讲道理、决定讲法律" |
| 以数治税 | 大数据、智慧税务 |
| **首违不罚** | 执法温度的**政策依据**，力度与温度类题必用 |
| 非接触式办税 | 便利化、数字化 |
| 税收共治 | 部门协同、社会参与 |
