# 报名填报与政审清单

> 2026-11 的教训：把「定向挂名单位」写进了工作经历，但那段没有社保记录。
> 明年（2028 年度国考，2027-10 报名）按这张表填，不要再凭印象。

## 一条总原则

> **报名表不是写「你干过什么」，是写「你能证明你干过什么」。**

三样东西必须对得上：**报名表的工作经历 ↔ 档案里的劳动合同/离职证明 ↔ 社保缴费记录**

对不上，就是政审唯一的真坑。

## 填表前必做（10 分钟）

1. 打开**掌上 12333**或「四川人社」App，导出个人社保缴费记录
2. 逐段核对：社保显示哪段在职，报名表就填哪段
3. **没缴社保的时段，一律不写成工作经历**
4. 把截图存到 `05_报考信息/` 下，留档

## 定向生怎么填

| 栏位 | 填法 |
| --- | --- |
| 学习形式 | **普通全日制**（定向不改变这个） |
| 定向 / 非定向 | 表格有这一栏，如实填「定向」；没有就不写 |
| 现工作单位 | 如实填；无则填「无」 |
| 工作经历 | 只填**毕业后**实际工作且有社保/合同的经历 |
| 在校期间 | 填学习经历，不填工作经历 |
| 人事档案存放单位 | 人才中心（写全称） |

**挂名但未实际到岗、无社保的定向单位，不填进工作经历。**

## 档案与离职

- 档案在人才中心 → 调档走正常流程，不是问题
- 录用前需**离职证明**（《劳动合同法》第 50 条：公司必须出具，不给可投诉/仲裁）
- 需处理的是离职证明，不是「解除协议书」
- 提前 30 天书面通知，留好送达证据

## 政审材料清单（提前备）

| 材料 | 从哪来 |
| --- | --- |
| 无犯罪记录证明 | 户籍地派出所 |
| 现实表现材料 | 原单位 / 社区 / 人才中心 |
| 人事档案 | 人才中心调转 |
| 学历学位证明 | 学信网 + 学位网 |
| 劳动合同、离职证明 | 本人保存 |
| 党团组织关系 | 如有党员身份，提前转接 |

## 时间线（2028 年度）

    2027-06  毕业
    2027-10  报名（按本清单填）
    2027-11  笔试
    2028-01  面试 + 资格复审
    2028-02  体检、政审
    2028-03  公示、录用

## 今年（2027 年度）的处理

已报名信息无法自行修改。若进面：

1. 资格复审时**主动说明**：「定向培养，在读期间未实际到岗，无社保」
2. 附定向培养协议作证
3. 向单位申请一份「定向培养备案」证明（一句话，盖章）

**主动说明是「填写有误」，被发现是「提供虚假信息」——两者结果完全不同。**

## 记住这一句

> 政审不怕你待业，怕你「说不清」。
